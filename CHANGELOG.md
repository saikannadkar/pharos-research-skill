# Changelog

All notable changes to this project will be documented here.

## [1.0.0] — 2026-06-09

### Added
- `search_and_summarize` — live web search with LLM summarization and focus modes
- `extract_structured_data` — field extraction from unstructured text to JSON
- `compare_assets` — side-by-side research comparison of two assets or protocols
- `get_pharos_wallet_summary` — live onchain wallet data from Pharos Atlantic Testnet
- MCP server via FastMCP framework
- Smoke tests for all 4 tools
- Full technical documentation
